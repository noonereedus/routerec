This repository is the foundation of the RouteRec: Strict Evaluation of Recommender-Agent Selection and Aggregation paper.

It includes the multi-layer recommender pipeline used to conduct the preliminary dependability experiments. The conclusions and the assembled pipeline were used to build the resulting router framework in the paper accepted at SIGIR 2026 AgentSearch.

Complete paper available here: https://arxiv.org/abs/2607.09908
